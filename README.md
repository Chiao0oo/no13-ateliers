# 十三號會所・故事工坊（NO. XIII）

一座以繁體中文為主、英文作為裝飾的多頁式靜態網站。

## 網站頁面
- 會所大廳（首頁）
- 主人檔案
- 故事圖書館
- 珍藏博物館
- 秘密花園
- 星象研究室
- 私人工作室

## GitHub Pages 部署
本專案附有 GitHub Actions 工作流程。進入 repository 的 **Settings → Pages**，將 **Build and deployment → Source** 設為 **GitHub Actions**。推送至 `main` 後會自動部署。

## 說明
- 支援桌面與手機版導覽。
- 目前為靜態展示網站，不含登入、留言或雲端資料保存功能。
- 未放入私人聯絡資料、住址或敏感資訊。
- Google Fonts 需要網路連線；若無法載入會使用系統字體。
